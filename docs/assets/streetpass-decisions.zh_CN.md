# 擦肩：已确认的设计决定

记录日期：2026-09-13；实现更新：2026-09-20。本分支已有第一版软件实现，真机验收尚未完成，详见[当前使用说明](streetpass-guide.zh_CN.md)。

## 离线编辑与二维码引导

- 无需托管服务、账号或专用手机应用。完整编辑网页保存在设备内，通过临时 Wi-Fi 热点提供。
- 进入「编辑名片」暂停蓝牙擦肩，显示包含临时热点凭据的 Wi-Fi 二维码。手机用系统相机扫描，并按系统要求确认加入。
- 连接后，通过 Captive Portal 尝试打开本地编辑页。自动弹出是尽力实现的兼容能力，可能使用系统网络登录窗口，而非完整浏览器。
- 若页面没有出现，按 OK 显示第二个本地编辑网址二维码，并附文字地址。扫描备用码前，手机必须已经连接设备热点。
- 保存后保持热点，待手机收到成功响应；退出编辑时关闭热点并恢复擦肩。
- 使用独立热点名称和临时凭据，仅在实体设备进入编辑时提供写入功能。iOS 与安卓均需验证连接、自动弹页、手动备用入口、保存与退出。

## 视觉方向

- 深色、低亮度、扁平、克制、清晰，略带可爱。已有灰绿色浅色与深色概念图仅是探索，尚未获确认为最终视觉目标。
- 已选择 A+D：融合 A 的 iOS 极简层级与分组列表，以及 D 的小信封可爱元素；原暖色已由下方确认色卡替代。保持 240 x 320 屏幕及上下／OK 操作，避免手机专属控件和高成本玻璃效果。融合评审图为[暖黑极简总览](../../assets/images/streetpass-ad-ui-overview-v1.png)；方向已确认，本次新生成版本仍是视觉提案，并非已实现的固件。
- 为节省生成额度，先比较少量关键页面，选定风格后再扩展全部页面。

## 已确认的色卡更新

用户提供科技深色色卡，替代 A+D 原暖色，保留已选布局与小角色。背景：`#0D0D11`；色块底色：`#141418`；主强调色：`#00AEEF`；少量高亮：`#00F0FF`；正文：`#D0D0D0`；次要文字：`#A0A0A0`。控制亮色面积，选中项使用低亮度深色背景，二维码仍用浅底深色码点。上述十六进制数值是实现目标，不代表生成概念图每个像素均精确匹配。

## 第一版视觉基准已确认

用户查看色卡调整结果后，确认采用 `streetpass-techdark-ui-overview-v1.png`。以此图作为第一版视觉基准：A 的清晰层级、D 的少量可爱元素，以及上方明确的科技深色色值。此前图片保留为历史备选；除非用户另有要求，不再生成风格备选。确认对象是视觉方向；二维码仍为示意，固件行为仍需实现和验证。
