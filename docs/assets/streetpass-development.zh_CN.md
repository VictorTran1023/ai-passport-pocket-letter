# 擦肩实现计划

范围见[产品决定](streetpass-decisions.zh_CN.md)。实现在独立工作树中完成，以独立擦肩仓库维护。真机验收仍待进行，不需要搭建服务器。

1. 实现并测试 UTF-8 字节限制、带版本的名片编码、有序蓝牙分片、确定性连接角色，以及保护收藏的名片淘汰策略。
2. 在受保护 cardid 后增加独立 NVS 分区，保存自己的名片及最多 100 位路人。落盘成功才报告成功；初始化失败时不清空身份或 Recovery。
3. 实现已批准的 240 x 320 深色 UI，使用上下／OK 实体键，包含小信封、真实二维码、电量、未读／收藏／删除和闲置调暗。
4. 实现临时加密热点、有边界检查的 DNS 引导和内置手机编辑页。仅实体设备进入编辑时允许保存，写入使用会话令牌。先停止 HTTP/DNS，再关闭 Wi-Fi，随后恢复蓝牙。
5. 使用自定义带版本 GATT 服务交换公开名片，验证并保存后再确认；区分本地收到和双方完成。限制单连接、会话超时及重试间隔。
6. 运行电脑测试及 ESP-IDF 5.5.3 编译／合并校验。真机验收需要两台设备及 iOS／安卓：擦肩、更新、重复相遇、中断传输、收藏已满、重启、二维码可读性、自动弹页与备用入口、功耗和 Recovery。

## 资源与行为预算

- 应用保持在 3 MB 内，16／24 像素压缩 2 bpp Noto Sans SC 常用字库及 16 像素 1 bpp 完整基本汉字回退字库保存在 Flash，详见[字体覆盖](../../assets/fonts/README.zh_CN.md)。不会把整个字体载入 RAM。
- RAM 只保存 100 人的精简索引，按需加载名片正文；启动不进行音频／图片解码，界面、无线和存储使用有限长度队列／缓冲。
- 公开名片可被附近兼容设备读取。首版不提供身份认证和私信；联系方式由本人明确选择公开。
- 扫码入网按手机系统要求确认。自动弹出编辑页尽力实现，第二个二维码始终指向设备本地编辑页。
- 不将真实个人资料、热点密码或硬件身份写入源码仓库。
