# 擦肩首版使用说明

擦肩以已确认的深色社交名片界面替代原演示菜单。蓝牙和 Wi-Fi 行为仍需真机验收，编译通过不代表硬件测试通过。编辑与交换名片无需账号、托管网页或互联网。

## 怎么使用

1. 打开「扫码编辑」。设备暂停蓝牙，开启临时 WPA2 热点。用手机系统相机扫描，并确认加入。这个热点本来就不提供互联网。
2. 手机可能自动弹出网络登录窗口。若未出现，按设备 OK 显示第二个二维码；也可在连好热点后打开 `http://192.168.4.1`。
3. 填写昵称、简介、留言和逗号分隔的兴趣。邮箱、Telegram 用户名、微信号为可选项。只有愿意把联系方式放进公开名片时，才打开相应开关。先预览，再确认保存。
4. 手机显示保存成功后，长按设备 OK 退出编辑。设备关闭热点，并恢复蓝牙；若设置中已暂停擦肩，则继续保持暂停。编辑模式十分钟后自动关闭热点。
5. 携带两台兼容设备靠近。名片通过验证并保存后，设备才显示收到提示。收到提示不代表双方一定在分开前都完成了交换。

应用保存自己的名片和最多 100 位路人。相同或较旧版本不会重复新增，也不会额外写入 Flash；较新版本标记为未读。空间满时，新朋友替换最旧的未收藏记录；如果全部已收藏，则拒收新名片。排序依据最近新增或更新的顺序，不是实际相遇时间；首版不显示相遇次数。

## 按键

| 页面 | 上／下 | OK | 长按 OK |
| --- | --- | --- | --- |
| 首页、列表、设置 | 选择 | 打开／更改 | 返回 |
| 名片 | 上一页／下一页 | 下一页／打开联系列表 | 返回 |
| 名片任意页 | 长按上键收藏或取消；长按下键请求删除 | 只有独立删除页才确认删除 | 返回 |
| 联系方式 | 选择 | 显示联系文字二维码 | 返回 |
| 编辑模式 | 无动作 | 切换入网码／网页码 | 关闭热点并退出 |

闲置调暗后，第一次按键只恢复亮度，不触发选中项目。擦肩、提示音和调暗设置保存在设备内。字体未覆盖的字符可能显示方框，但完整 UTF-8 文字仍保留在名片中。联系二维码包含界面所示文字；微信不会自动加好友。

## 首版边界

- 公开名片可被附近兼容蓝牙客户端读取。协议提供分片、UTF-8 验证和传输损坏校验，不提供身份认证或私密聊天。
- 随机应用 ID 独立于硬件 `cardid`。GATT v1 使用自定义 128 位服务、14 字节分片，支持最小 MTU 23，会话超时为 20 秒。广播厂商 ID `0xFFFF` 用于本实验原型，不是正式分配的生产厂商编号。
- 应用 ID 字典序较小的一方发起连接。信号强度仅粗略过滤，不能测量距离。成功交换后冷却五分钟，已连接但失败的尝试冷却十秒；更新也可能受到冷却延迟。
- 编辑仅支持一台手机，使用随机热点密码及独立会话令牌。服务器验证字节长度和版本；网页不访问外部服务。
- 昵称／简介／留言／兴趣／邮箱／Telegram／微信的 UTF-8 上限依次为 48／96／144／96／80／48／64 字节，常见汉字占三个字节。
- 名片 NVS 分区 `spdata` 位于 `0x360000`，大小 `0x80000`。初始化失败不自动清空数据。应用分区仍为 3 MB，保留 `cardid`、Recovery 及长按上键五秒入口。
- 首版不涉及 NFC，不需要手机应用、远程名片网页、配对、账号或位置记录。

## 验证和下一步真机检查

在 ESP-IDF 5.5.3 环境运行 `./tools/validate.sh`，它会检查文档与工作流、原有和擦肩主机测试，再编译并校验合并镜像。存储主机测试使用 NVS 替身，不能证明 Flash 寿命或断电行为。

`tests/render_sp_ui.c` 在电脑上用示例资料渲染真实 LVGL 页面；40 KB LVGL 内存池与固件一致，但不模拟 ESP32 总内存、DMA、Wi-Fi 或蓝牙开销。

正式使用前，需要两台板子验证：步行擦肩、长名片、同时发现、重复相遇与更新、中断传输、收藏已满、重启保存、待机耗电、声音，以及反复切换蓝牙／热点。使用 iOS 和安卓检查扫码、自动弹页、备用入口和保存中断；在真实设备验证 Recovery 入口。尚未刷机或发布通过真机验证的版本；源码发布与设备验收分开记录。
